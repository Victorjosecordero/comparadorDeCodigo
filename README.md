# VP Diff · Comparador de código

Herramienta web para pegar dos versiones de un archivo y visualizar sus cambios línea por línea.

## Uso local

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático.

## Características

- Comparación línea a línea en el navegador.
- Resaltado de líneas añadidas y eliminadas.
- Números de línea y resumen de cambios.
- Datos privados: no se envía contenido a ningún servidor.
- Diseño adaptable a escritorio y móvil.
